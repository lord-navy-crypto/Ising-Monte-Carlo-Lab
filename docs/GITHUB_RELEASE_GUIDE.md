# GitHub release guide

This directory is prepared to be used directly as a Git repository root.

Included repository infrastructure:

- CI workflow for Python 3.10, 3.12, 3.13, and 3.14
- Dependabot configuration
- bug/feature issue forms
- pull-request template
- contribution, security, and conduct documents
- `.gitignore`, `.gitattributes`, and `.editorconfig`
- release checklist
- automatic localhost port selection for the macOS and Windows launchers

Before a public release, the repository owner should choose and add an explicit software license if external reuse is intended.
